# Feature mindmap

## Feature mindmap

```mermaid
mindmap
  root((drive-the-task))
    The loop
      Do everything that does not need the user
      Stop at the first real gate
      Ask for one thing
      Resume immediately
    Gates
      Credentials, MFA, CAPTCHA
      Account creation
      Tax and bank identifiers
      Signatures and attestations
      Submit on a government application
      Payments
      Outbound messages
      Accepting terms
      Facts only the user knows
    Wording
      Numbered steps
      One action per step
      Name the exact field or button
      Recap at the end of every response
    Before driving
      Look for saved state
      Check what already exists
      Have the data ready
      Announce unfillable fields once
    Recovery
      Session timeout
      Stubborn fields
      Read before acting
    Honesty and records
      Prepared vs done
      Confirmation number and what is awaited
    Credential discipline
      Never transcribed
      Grep afterwards
    Distribution
      Skill folder
      Packaged .skill zip
```
